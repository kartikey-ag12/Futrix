# Futrix - Project Context

Futrix is a centralized financial intelligence platform that provides dashboards, reporting, forecasting, and AI insights by integrating with accounting software like Xero and Excel. It is built using Next.js, React, TypeScript, and Tailwind CSS.

## Features

- **Authentication System**: Secure login and signup flows for user onboarding and session management.
- **Interactive Dashboard**: A centralized hub featuring real-time KPI cards, revenue charts, and cash flow visualizations.
- **Accounting Integrations**: Dedicated endpoints and UI components to seamlessly connect and sync data with Excel and Xero.
- **AI-Powered Insights**: An AI engine utilizing the OpenAI API to analyze financial data and provide automated insights.
- **Financial Forecasting**: Predictive tools and dedicated modules for modeling future financial metrics and trends.
- **Comprehensive Reporting**: Modules for generating detailed reports, tracking transactions, and exporting financial data.
- **Marketing & Support**: Marketing landing pages showcasing features/pricing, alongside an integrated support modal for users.
